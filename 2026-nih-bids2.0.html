BIDS Features

  • Modular composition
    • related: YODA → now STAMPED principles (more later)
  • Consistent folder composition
    • [study/]<dataset>/sub-<label>/[ses-<label>/]<datatype>/
    • You have seen one BIDS dataset -- you have seen them all!
  • Expressive file naming schema
    • related: Naming Things by Jenny Bryan; Project structure by Danielle Navarro; DataLad RDM Course — How to name a file
  • Standard file formats
    • NIfTI / TSV / JSON / EDF / BrainVision / … per modality (see spec)
  • Documented metadata
    • JSON sidecars + TSV "summaries" + inheritance principle
  • Human- and machine-readable data
    • Human-readable specification (Markdown → HTML / PDF)
    • Machine-readable schema (YAML) — validator, docs, and tooling generated from it
    • BIDS-apps (such as mriqc, fmriprep, etc) for turnkey pipelines
    • PyBIDS, bids2table, snakebids etc. for scripting
  • Constant evolution
    • via BIDS Extension Proposals (BEPs) and open PR review
