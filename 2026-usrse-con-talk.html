What BIDS is made of

  • One layout, declared — sub-<label>/[ses-<label>/]<datatype>/. You have seen one BIDS dataset, you have seen them all.
  • File names that parse — entities in a fixed order, not prose
  • A short list of allowed formats per data type, instead of “whatever wrote it”
  • Metadata with a place to live — JSON sidecars, TSV tables, and an inheritance principle so it is said once
  • Readable by both — a prose specification for humans and a machine-readable schema the validator, the docs and the tooling are generated from
  • An amendment process — BEPs and open PR review, so the standard can be wrong and still recover

None of this is neuroimaging. It is the anatomy of a standard your field can adopt — and the contract an agent can be held to.

Not just rhetoric: a structured neuroimaging harness moved first-choice tool-selection accuracy from 23.3% to 93.6% across seven models — Chen, …, Poldrack, Bringing analytic rigor to agentic AI for science, arXiv:2608.19902, 2026 (brain-researcher.com).

This is the hinge of the talk. An unstructured tree does not give the agent less information — it gives it *ambiguous* information, which is worse, because a model will resolve ambiguity with a plausible guess rather than an error.

  • Peak RSS over time, per process. Not your memory of it.

  • Measured, from the run you already did.
“What did it print before it died?”
  • Captured, versioned, next to the outputs.

HBR, Feb 2026: “AI doesn’t reduce work, it intensifies it”

Agent-rate output demands agent-rate review. You cannot hand-inspect what an agent produces in an afternoon. The only things that scale with it are standards (so correctness is checkable) and provenance (so the history is reconstructable).
