## Presentation Overview

### Core Themes

1. **Observability** - duct, bash history, zoom recordings, ReproStim
2. **Hierarchical composition** - BIDS, submodules, OpenNeuroDerivatives, condensed frontiers
3. **AI as amplifier, not replacement** - structured data enables better AI
4. **Provenance everywhere** - git commits, run records, CI logs, BEP028
5. **Independence through standardization** - BIDS/YODA enable federation without centralization

### Structure (Proposed)

- **Act I**: YODA Foundation (principles 1-3)
- **Act II**: Execution & Workflows (SciOps, ReproFlow, tools)
- **Act III**: Hierarchical Composition (BIDS as YODA exemplar)
- **Act IV**: AI Frontier (structure enables intelligence)
- **Act V**: The Vision (every lab, a YODA)
