01 · STAMPED

The seven principles

Self-contained
Reach all essential components from one project root.
Tracked
Identify every component and record changes and computational provenance.
Actionable
Provide executable procedures and reproduction instructions.
Modular
Separate components for reuse and recombination.
Portable
Version environment specifications and avoid undocumented host dependencies.
Ephemeral
Run in fresh, disposable environments built from recorded specifications.
Distributable
Make components persistently retrievable in their recorded state, with explicit licenses.

Each principle is a spectrum, supporting incremental improvement. STAMPED paper.

The experiment

Test the skills
through the work

Do successive revisions improve scientific adequacy, reproducibility and consistency?

  1. RunFresh agents address the same scientific question.
  2. AssessIndependent judges inspect the research object and attempt replay.
  3. ReviseUse recurring findings to improve and compress the skills.
  4. RepeatTest the next pinned revision with fresh agents.

Three iterations of testing and revision. In the final iteration, evaluate without further tuning.

Improving the guidance

Assess without prescribing

Specifying tools or output formats aids assessment but can prescribe the practices being evaluated. The common task left methods and delivery to workers; coordinator preservation was recorded separately. Bound repairs, preserve limitations and advance to the next planned round.

We revised the STAMPED research-loop skill to request an executable setup recipe or retrievable pinned source alongside the runtime identity. Fresh agents in the STAMPED condition tested the revised skill.
