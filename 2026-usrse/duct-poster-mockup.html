S1Output nobody kept

Humans and agents now run commands side by side. The terminal output is the evidence, and it is either bloating an agent's context window or gone past the scrollback.

what the agent sawwhat one nebari deploy printed: 3,227 lines

Wrap it: duct <cmd> instead of <cmd>. The command runs unchanged and leaves four files.

$ duct nebari deploy …
→
duct
→
stdoutstderrinfo.jsonusage.jsonl
Scope. Cheap one-offs do not need this; agents are good at those. duct earns its keep when execution is expensive, slow, or dangerous, where “just try again” is not an option and every attempt should be reviewable.

S4A human audits the agent: bug replication

The agent writes a reproducer and runs it under duct, numbering each step in the tag:

$ duct -p logs/1_ -m "1: reproduce user's bug"                      ./repro.sh
$ duct -p logs/2_ -m "2: simplified reproducer to test hypothesis"  ./repro.sh
$ duct -p logs/3_ -m "3: verify fix"                                ./repro.sh

The agent reports “fixed”. You do not take its word:

$ con-duct ls -F prefix message exit_code logs/*info.json
logs/1_  1: reproduce user's bug                      1
logs/2_  2: simplified reproducer to test hypothesis  1
logs/3_  3: verify fix                                0

Each row has the exact command and full stderr behind it. Auditing is reading three tagged records, not scrolling a transcript. (simulated; to be staged on a real duct bug)

S9Honesty box

  • Output is written to disk: do not wrap commands that print secrets.
  • Programs that check isatty() take their non-interactive path (README has workarounds).
  • Sub-second commands leave four files and no samples. POSIX only; ps numbers are approximate; cgroup measurement in progress (con/duct#438).
  • A process that lives a few ms is invisible to a 1 s sampler, duct's own ps included: the overhead panel's time -v total is nearly twice what duct saw of itself.
  • Resource peaks paid off on SLURM; for agentic work the value has been the logs and con-duct ls. Wrap the runs you cannot afford to repeat.
